Edufeed einbinden – HTML-Snippets

Termine und Lernmaterialien aus Edufeed in jede Webseite einbetten – ein <div>, ein <script>, fertig. Kein iframe, kein Build, keine Abhängigkeiten.

Schnellstart copy & paste

Das Snippet funktioniert überall, wo man eigenes HTML einfügen darf – HTML-Boxen in CMS, Moodle-Textblöcke, statische Seiten. Es lädt die Daten direkt per WebSocket vom Relay und rendert sie an Ort und Stelle. Mehrere Boxen auf einer Seite sind kein Problem; das Script muss nur einmal eingebunden werden.

<!-- Kommende Termine -->
<div data-edufeed="events" data-limit="5"></div>

<!-- Lernmaterialien zum Fach Religion -->
<div data-edufeed="materials" data-subject="Religion" data-limit="8"></div>

<!-- Interaktive Suche über alle Materialien -->
<div data-edufeed="search"></div>

<script src="https://edufeed-org.github.io/edufeed-examples/embed/edufeed-embed.js"></script>
Das Script am besten nach den <div>s einfügen. Wird es früher geladen, bindet es sich trotzdem nach dem Laden der Seite an alle data-edufeed-Elemente.

Nur Termine eines bestimmten Veranstalters

Mit data-author lassen sich Termine auf einen Nostr-Schlüssel einschränken – als npub… oder Hex. Vergangene Termine zeigt data-when="past", alle data-when="all".

<div data-edufeed="events" data-author="npub1…" data-when="all" data-layout="list"></div>

Termine einer Community

Wenn mehrere Personen für eine Einrichtung eintragen, ist data-author unpraktisch: Es filtert nach dem Schlüssel, der den Termin signiert hat, also nach der einzelnen Person. Mit data-community zeigt das Widget stattdessen alles, was Mitglieder in eine Edufeed-Community geteilt haben – egal, wer es angelegt hat. Angegeben wird der Schlüssel der Community (npub… oder Hex), hier die Edufeed-Community selbst.

<div data-edufeed="events" data-community="npub1hhpplya3ut9h2cyvant6pgq2w7thnkfk0hyhnz7e7gflqmy4h3yqp2p4pk" data-when="all" data-layout="list" data-limit="6"></div>

Materialien einer Community

Analog zu den Terminen: data-community zeigt die Materialien, die in eine Community geteilt wurden. Lässt sich mit data-author kombinieren („nur Beiträge von X in Community Y“) und funktioniert auch im interaktiven Suchfeld.

Aus eigenem JavaScript

Das Script stellt window.EdufeedEmbed bereit. Damit lassen sich Boxen auch dynamisch anlegen, z. B. nach einem Klick oder mit Werten aus dem eigenen System:

EdufeedEmbed.mount(document.getElementById('box'), {
  type: 'materials', search: 'Advent', layout: 'list', limit: 5
});

// Wenn die Daten da sind, feuert das Element ein Event:
box.addEventListener('edufeed:loaded', e => console.log(e.detail.items));
// Beim Suchfeld enthält e.detail.query zusätzlich den gesuchten Begriff.

Eigenes Aussehen

Alle Elemente tragen Klassen mit Präfix ef- (.ef-card, .ef-row, .ef-title, .ef-badge, …). Eigene CSS-Regeln, die nach dem Script geladen werden oder spezifischer sind, überschreiben das mitgelieferte Styling. Schriftart und Textfarbe erbt das Widget von der umgebenden Seite.

Was man wissen sollte

Technische Voraussetzungen

  • Die Seite muss eigenes <script> erlauben (manche CMS filtern das in HTML-Boxen heraus).
  • Eine Content-Security-Policy darf wss://*.edufeed.org und edufeed-org.github.io nicht blockieren.
  • Die Daten werden beim Seitenaufruf live vom Relay geladen – kein Caching, kein Server dazwischen.

Nur lesen

Das Snippet zeigt Daten an. Zum Eintragen von Material oder Terminen braucht es einen Nostr-Schlüssel zum Signieren und Schreibrechte auf dem Relay – das Edufeed-Material-Relay akzeptiert nur freigeschaltete Autoren. Ein Eingabe-Snippet ist in Vorbereitung; bis dahin: app.edufeed.org oder per CLI mit nak (siehe Data-Pool-Guide).

Selbst hosten

Die Datei edufeed-embed.js ist eine einzelne, abhängigkeitsfreie JavaScript-Datei – sie kann auch auf den eigenen Server kopiert und von dort eingebunden werden. Wer tiefer einsteigen will: die Termin- und Material-Demos zeigen das Protokoll Schritt für Schritt.
